FAQ

Straight answers.

Anything else? Ask us during the demo, or write to hello@aknologia.com.

Does the app read our code or prompts?

No. It reads local session files only to extract token counts, model names, and timestamps. Everything else is discarded on the laptop.

Will budgets block Claude Code or Codex?

Never. Budgets email admins and notify the developer. Tools keep working.

How is cost calculated?

At public API list prices for each model. On a subscription, treat it as a consistent measure of usage rather than your invoice.

How do developers sign in?

Admins invite them by email. They set a password from the invite link, then sign in with email and password. Resets use a one-time code.

Where is the data stored?

In a managed Postgres database. Enterprise plans can choose a dedicated region.

Can we try it before buying?

Yes. Starter is free for up to 3 members, and paid plans include a 14-day trial with no card.
